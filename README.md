# FizzBuzz API

[![Go](https://img.shields.io/badge/go-1.26-00ADD8?logo=go)](https://go.dev/)
[![Docker](https://img.shields.io/badge/docker-compose-2496ED?logo=docker&logoColor=white)](docker-compose.yml)

Customizable FizzBuzz REST API written in Go. It includes request statistics,
MongoDB persistence, Swagger documentation, OpenTelemetry tracing and a
Docker Compose setup.

## Run

### Docker Compose

Requires Docker and Docker Compose.

```bash
cp .env.docker.dev .env
make up
```

Services:

- API: <http://localhost:8080>
- Swagger UI: <http://localhost:8080/swagger/index.html>
- Jaeger: <http://localhost:16686>
- MongoDB: `localhost:27017`

Stop everything with `make down`.

### Local Go process

Requires:

- Go 1.26+
- `make`
- A reachable MongoDB instance, e.g. `docker run -p 27017:27017 mongo:7`

```bash
cp .env.dev .env
make run
```

Tracing is enabled by default and expects an OTLP/HTTP collector on
`localhost:4318` (e.g. Jaeger, see the Docker Compose section). Set
`TRACING_ENABLED=false` in `.env` if you don't want to run one locally.

## API

### Generate FizzBuzz

Please refere to Swagger UI: <http://localhost:8080/swagger/index.html>

`GET /api/v1/fizzbuzz`

Required query parameters: `int1`, `int2`, `limit`, `str1`, `str2`.

```bash
curl "http://localhost:8080/api/v1/fizzbuzz?int1=3&int2=5&limit=15&str1=fizz&str2=buzz"
```

Multiples of both divisors return `str1 + str2`.

### Most frequent request

`GET /api/v1/statistics`

Returns the most requested parameter set and its hit count.

### Health

`GET /healthz`

## Configuration

Configuration is loaded from environment variables. Use `.env.dev` for a
local process and `.env.docker.dev` for Compose.

| Variable | Default | Purpose |
| --- | --- | --- |
| `HTTP_ADDR` | `0.0.0.0:8080` | Listen address |
| `HTTP_PORT` | `8080` | Published host port in Compose |
| `PUBLIC_BASE_URL` | `http://localhost:8080` | Public API URL |
| `MONGO_URI` | `mongodb://localhost:27017` | MongoDB connection |
| `MONGO_DATABASE` | `fizzbuzz` | MongoDB database |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | `localhost:4318` | OTLP/HTTP endpoint |
| `TRACING_ENABLED` | `true` | Enable tracing |
| `ENVIRONMENT` | `development` | Runtime environment |

Inside Compose, use `mongo:27017` and `jaeger:4318` instead of `localhost`.
